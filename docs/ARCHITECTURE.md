# System Architecture

## GPIO mapping

| Color | GPIO |
| ----- | ---- |
| Blue | GPIO 18 (Physical Pin 12) |
| Green | GPIO 19 (Physical Pin 35) |
| Yellow | GPIO 21 (Physical Pin 40) |
| Red | 5V (Physical Pin 2 or 4) — or 3.3V (Pin 1) for lower volume/power |
| Black | GND (Physical Pin 6, 9, 14, 20, 25, 30, 34, or 39) |
